# Pulse Messenger

Pulse Messenger - это веб-мессенджер на `Node.js`, `Express`, `Socket.IO` и `SQLite`.

Подходит для личного сервера, VPS или домашнего хоста. Есть личные чаты, комнаты, приглашения, реакции, опросы, загрузка файлов, админка и поддержка сессий.

## Как это устроено

- backend работает на Node.js
- данные хранятся в SQLite
- frontend отдается из `public/`
- в продакшене обычно используется `nginx` или `caddy` перед приложением

## Установка

### Вариант 1. Быстрый запуск локально

```bash
npm install
cp .env.example .env
npm start
```

Открой `http://localhost:3010`.

### Вариант 2. Установка на сервер

```bash
sudo bash scripts/install-anywhere.sh
```

Скрипт сам спросит нужные параметры и доведет установку до конца.

Обычно он делает вот что:

- ставит зависимости и Node.js
- копирует проект в выбранный каталог
- создает `.env`
- поднимает сервис через `systemd`
- настраивает `nginx`
- при необходимости включает HTTPS
- создает первого администратора

### Вариант 3. Автообновление

```bash
sudo bash scripts/install-auto-update.sh
```

Этот скрипт ставит таймер, который периодически проверяет GitHub и обновляет серверную установку.

## Настройки

Основные переменные лежат в `.env.example`.

- `PORT` - порт приложения
- `HOST` - адрес привязки
- `JWT_SECRET` - секрет для токенов
- `CORS_ORIGIN` - адрес фронтенда
- `DB_PATH` - путь к базе
- `UPLOADS_DIR` - путь к загрузкам
- `HTTPS_KEY_PATH` / `HTTPS_CERT_PATH` - если нужен HTTPS напрямую в Node

Если переносишь старую установку, сначала копируй базу и `uploads`, потом запускай установщик.
